# database/

Archivos relacionados con la base de datos PostgreSQL.

## Archivos

| Archivo | Descripcion |
|---|---|
| `init.sql` | Script SQL con el schema completo de Northwind (tablas + datos de ejemplo). Se ejecuta al levantar el contenedor de PostgreSQL por primera vez. |
| `seed.py` | Script Python para poblar la BD con datos de prueba en entorno de desarrollo. |
